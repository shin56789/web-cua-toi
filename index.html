Tạo token ở đâu?
  1. GitHub → ảnh đại diện → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → chọn đúng repo của quán.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate, copy token và dán vào ô trên. Token chỉ lưu trong trình duyệt của bạn, không nằm trong code website.
